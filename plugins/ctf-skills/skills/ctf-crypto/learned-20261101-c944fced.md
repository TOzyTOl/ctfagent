# Ring-LWE 折叠判别：稀疏倍式降维 + Gram 最优基 + BKZ 批量区分

## 什么时候用

- 题目给多项式环样本 `(a, b = a*s + e mod f)`，`f` 是 n 次模多项式（如 512 次），`s/e` 是小系数（离散高斯 σ≈3.4 或 0/1），**每个样本的 s、e 都重新生成**，只要求逐样本判别（区分 RLWE 样本与均匀随机样本，得到每个样本的 1 bit），不要求恢复 s。
- `factor(f)` 在 GF(p) 上裂成几十~几百个低次（≤6 次）因子。随机 n 次多项式的低次不可约因子期望只有 ≈log n 个；明显更多说明"高度可约"本身就是植入结构（本题题名三个 R 就是这个梗）。
- 直接对每个样本做 2n+1 维 uSVP 不可行（要 BKZ-150 量级 × 几百个样本），必须先把维度折下来。判别的关键是：**不需要解出 s，只需要格里有范数异常短的候选**。

## 怎么做

1. **结构侦察**：factor f，统计因子次数分布并与随机基线对照；然后在随机子空间上做 LLL/BKZ 扫短向量，对每条短向量算 `gcd(v, f)`（**必须算 gcd 而不是只测整除**——规约给出的常是弱因子的倍数，测整除会把全部命中误丢）。收集所有不同的 gcd 与生成它们的稀疏短向量。
2. **倍式评分**：对每个候选稀疏倍式 v，量化 `x^k mod v` 的提升系数增长（稀疏递推下通常仍小，如最大系数仅 15）；再算嵌入格间隙 `det^(1/dim) / 目标范数`。gcd 次数更低 → 行列式更大 → 间隙更好；系数达到 p 量级的 gcd 本身不可用（投影噪声会大 GH 好几个数量级）。
3. **折叠**：取 `Fs = gcd(f, v_best)`。样本多项式对 Fs 取余降维；折叠坐标由一个小 Gram 格的最优基给出（对 Gram 矩阵的基做 LLL 最小化 Frobenius 范数，本题 `||C||_F ≈ 27.84`），把 s、e 折成 ~9 维坐标，嵌入维度从 1025 降到 ~181。
4. **嵌入与自校准**：每样本构造 Kannan 嵌入，目标向量 `(e', -s', 1)`，范数 ~400。**先在自造合成样本上验证目标向量确实落在格里（方程残差全零、范数在预期区间），再碰真实数据**——否则"找不到短向量"分不清是格构造错还是规约不够强。
5. **判别**：LLL → BKZ-50 → BKZ-60（fplll 官方 `strategies/default.json` + `flags=BKZ.GH_BND|BKZ.MAX_LOOPS`）。看末坐标 `|t|=1` 的最短行范数：RLWE 样本 ~380–490，均匀样本 ~6e3–1.1e4，阈值取中间（950）即可零歧义。批量多进程并行（18 路 × ~2 分钟/样本）。
6. **全量校验**：用明文结构先验（如 flag 前缀 + UUID 字节布局）把候选明文重编码成比特流，与全部测量比对；重复运行的结果应零失配，缺位样本单独补跑。

## 坑

- **BKZ-50 失败 ≠ 均匀样本**：约一半 RLWE 样本在 BKZ-50 仍找不到短行（范数 ~1e4，与均匀样本不可区分），必须升 BKZ-60 再下结论，否则会把一半 0 判成 1。
- fpylll 不带剪枝策略文件会直接报错（"Cannot open strategies file"）：从 fplll GitHub 拉 `strategies/default.json`，`strategies=` 显式传路径。
- `max_loops` 参数必须配 `flags=BKZ.MAX_LOOPS` 才生效，否则 BKZ 会白跑很多轮。
- `GH_BND` 在初始基离 GH 很远时会锁死枚举半径、不改进——先 LLL，GH_BND 用在接近收敛的阶段。
- fplll 偶发 "infinite loop in babai" SIGSEGV（dd 精度也躲不过）：换 block size 序列重跑即可通过。
- Windows 无 fpylll wheel：`docker run python:3.12-slim-bookworm` + 容器内建 venv 是最省事路线；杀批量容器要 `docker kill`（杀 docker run 客户端进程没用）；multiprocessing Pool 的进度统计因分块而失真，以落盘行数为准。

## 已证伪的路线（别再走）

- **单因子投影**（对 f 的某个不可约因子取余做判别）：投影后 s、e 严格均匀，单分量零信息——本题 261 个因子全部实测排除。
- **把 gcd(f,v) 当短除子直接嵌入**：该 gcd 系数是 p 量级，投影噪声比 GH 大 6 个数量级；可用的是它的稀疏倍式 v，不是 gcd 本身。
- **假设短向量必整除 f**：范数 2 的短向量只是弱因子的稀疏倍数；"只测整除"的扫描会把关键倍式全部漏掉——本题的决定性倍式（范数 2、`x^100+x^50-x^20+1` 型）正是这样漏掉又被 gcd 扫回来的。
- **找"增长很小的低次商环"**：逐因子测 `x^k mod g` 的增长，全部与随机无异（系数涨到 p/2 量级），且无一满足 `x^N ≡ 1 (N ≤ 4096)`——植入结构不通过这条路起作用。
