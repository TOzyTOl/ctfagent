# 技术笔记：E-string 拼接注入 → 后台弱口令 → webapp 内 JSP → SUID 助手

## 什么时候用

- 搜索/列表参数直接拼进 `ILIKE E'%<q>%'`：诊断/报错页能看到 `E'` 前缀；直接输入 `'` 不报错（被翻倍），但 `\'` 会改变语义。
- 有一层“非法字符”黑名单，按整词拦 `or/and/union/;/< /chr/substr/concat/cast/left/right/...`，却放过 `$$...$$`、`rpad/reverse/trim/length/replace`。
- 后台有媒体/附件上传，只校验“是不是图片”。
- 拿到命令执行后，`/flag` 是 `root:root 0400`，容器里有自定义 SUID 工具。

## 怎么做

1. **先拿 SQL 形状**：给参数塞 `%00` 触发数据库诊断页（SQLSTATE 08P01），失败语句会回显 `E'% %'` 拼接。逐词测黑名单边界，别假设全拦。
2. **E-string 闭合**：`q=\' = (SELECT NOT(cond)) -- `。应用把 `'` 翻倍成 `''`，`\'` 变成 `\''`；E-string 把 `\'` 解析为字面量单引号，第二个 `'` 关闭字符串，`--` 注释尾部。
3. **黑名单外的盲注原语**：字面量一律用 `$$...$$`；取第 i 字符 `reverse(rpad(reverse(rpad((X),i)),1))`；字符集二分 `length(trim(both $$SET$$ from ch))=0`；判真假 `= (SELECT NOT(cond))`。
4. **先修 oracle 再用它**：固定包装 `%'` 会命中“标题以 `'` 结尾”的行，条件真假都返回行。自建一条 marker 记录，判据改成“结果里是否出现 `/article/<id>`”；每次先跑 true/false 阳性对照，响应不是正常页面就重试，别把超时/重启当 False。
5. **读后台账号**：`admins` 表通常无盐 `sha256(password)`，rockyou + 常见变体破弱口令；后台往往还有上传类功能，是下一跳。
6. **上传到执行**：用 1×1 PNG 头 + `.jsp` 过图片校验。文件名设 `.`/`..` 触发 `Is a directory`，报错会带出绝对路径；若路径在 `webapps/ROOT` 内，`.jsp` 会被 Jasper 执行。用 `out.print("MARK")` 确认是真执行（只回 `<% ... %>` 原文说明是静态处理器）。
7. **绕过清理**：非图片扩展名常被定时清理，必须上传后立刻请求；让 JSP 把自身复制到 `application.getRealPath("/")+"c.jsp"` 之类的清理目录之外，得到持久 shell。
8. **提权**：`find / -perm -4000`；自定义 SUID 助手用 `strings` 看是否把参数拼进 `/bin/bash -c "... %s ..."`。只挡 `..`/`/` 的过滤挡不住 `;`、`$()`、反引号，`helper "x; cat /flag"` 直接以 `euid=0` 执行。PID 1 的 entrypoint 注释常直接写明预期提权路径。

## 坑与判据

- `chr/substr/concat/cast/left/right/strpos/split_part/get_byte/convert_to/::` 都被拦；`length/rpad/reverse/trim/replace/upper/lower/$$` 可用。
- 受限角色下 `pg_read_binary_file`/`pg_ls_*` 常无 EXECUTE：`has_function_privilege(current_user, ...)`、`pg_has_role` 一条布尔就能判，别把权限错误当成“文件不存在”。
- `ts_stat()` 能执行任意 SELECT 字符串（可跑子查询），但 SPI 只读：UPDATE/数据修改 CTE 会报错，不能当写库/读文件用。
- 盲注“0 行”不是结论：先看页面类型；共享实例/并发会把容器打崩，降到单线程并做重试。
- 上传后的 `.jsp` 若能看到 `<%` 原文，说明没有执行；只有脚本输出（标记串）才算 RCE。
- SUID 助手的过滤通常只针对路径；shell 元字符是判据，先用 `id` 看 `euid`。
