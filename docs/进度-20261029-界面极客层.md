## 1. 这一轮做了什么

### 1.1 终端语法（A）

| 位置 | 效果 |
|---|---|
| `.msg.assistant .who::before` | 主 agent 每轮发言前一个**画的**直角小箭头（ochre） |
| `.console .ev::before` | 日志每条事件前 `›`（`--rule` 灰），事件类型按 `k-<kind>` 上色：`k-agent` ochre、`k-flag` 绿 |
| `.ws-title .sub::before` | 运行身份行同一个箭头 |
| `.palette-caret` | 命令面板输入头同一个箭头 |
| `kbd` 全局 | 平键帽：发丝边、底边 2px、小圆角，不做内阴影/渐变 |
| `.composer-keys` | 输入框右侧 `Enter 发送` 常驻提示（不塞进 placeholder——placeholder 在第一次击键时就消失，而那正是要判断 Enter 还是 Shift+Enter 的时刻） |

**箭头为什么是画的**：`❯`/`❮` 这一类字形在几种等宽字体里没有，会静默 fallback 成豆腐块，而这是全页最需要显得精确的一行。用 `border-right + border-bottom + rotate(-45deg)` 画。

### 1.2 命令面板（C）

`Ctrl+K` / `⌘K` 打开；`↑↓` 游走、`Enter` 执行、`Esc` 关闭；顶栏右侧「跳转 Ctrl K」是入口也是发现面。

- 排名：`页面(5)` → `动作(按页面 DOM 现取)` → `任务(按评分)`。评分 100/80/50/30 分档，支持多词 AND（`sql 121` 能搜）。
- 任务行标签是 `#78  <challenge_name>`，检索词包含 id、题目名、方向、objective——`#121` 能搜，题目名也能搜。
- 动作是**读 DOM** 得来的，不是硬编码：有输入框才有「聚焦输入框」，有日志页签才有「打开日志」。
- 键盘说明在面板底部一行：`↑↓ 选择 / Enter 执行 / Esc 关闭 / N 项`。

### 1.3 无障碍与键盘可达性

- **跳转链接**（`跳到正文`）：`base.html` 里第一个 body 元素，平时在视口上方，第一个 Tab 停靠时落到顶栏下。任务轨一天能堆九十来个链接，键盘用户不该先走完它们。
- `html { scroll-padding-top: calc(var(--topbar) + 8px) }`：header 是 sticky，任何被滚到的目标（跳转链接、锚点、聚焦控件）都不会藏到栏底。
- `#main` + `tabindex="-1"` 出现在全部六个页面（`workspace / new / competitions / settings / docs / index`），实测六个路由都存在。
- 面板内 `Tab` 被 `preventDefault`：焦点留在弹窗里，不会漏到背后的页面。

## 2. 修掉的 bug（都是量出来的，不是看出来的）

### 2.1 【严重】手机上命令面板整个不渲染

`html.palette-open, html.palette-open body { overflow: hidden }`（打开面板时锁滚动）里的类名和顶栏按钮的 `.palette-open` **撞了**。900px 断点里有 `.palette-open { display: none }`（窄屏藏按钮），命中 `<html>` 后把**整个 `<html>` 元素**一起 `display: none` 了。

实测链：

```
加类后  html: h 844 → 0, display block → none, frame 17333 → 0
探针把 overflow 改回 visible（.palette-open 仍在）→ 仍 0×0   ← 证明不是滚动锁的锅
```

修法：状态类改名 `.scroll-locked`，按"它做的事"命名，注释写清为什么不能用 `.palette-open`。
修后实测：390 / 900 / 901 / 1440 四档，手机面板 390×844 撑满、桌面 640×560 居中，Esc 后 `html` 类名回空、滚动恢复。

### 2.2 面板光标卡在第 40 行

`movePalette()` 走到窗口边界时把 `paletteVisible` 扩到 41 并 `renderPalette()`，但 `renderPalette()` 开头**无条件** `paletteVisible = min(len, 40)`，把刚扩的窗口收回去了——79 项里第 41 项之后键盘永远够不着。

修法：`renderPalette(keepWindow)`，扩窗时传 `true` 并 `return`（那条路径自己已经改好了 DOM 的 `.on`）。
修后实测：连按 45 下 → 第 46 行（`46/79 项`）；再按 40 下 → 绕回开头（`79 项`，79 行全渲染）；输入新查询后窗口回到 40。

### 2.3 `/api/runs` 拿到的是旧数据结构

`server.py:1318` 早就加了 `challenge_name` / `category` 的补全，但**旧进程还占着 8789**。`start.cmd -Restart` 打印「已停止 pid 57840，端口 8789 已释放」，实际占端口的是 21:12 启动的 pid 29520/35164，进程从未被杀。表现是面板任务行显示 `#78 ?`。

修法：按端口查 pid → 杀 → 删 `ctfagent/__pycache__/server.cpython-312.pyc` → 重启。
修后实测：`rows 69`，键里出现 `challenge_name` / `category`，面板任务行变成 `#78  http://hbc2.haobachang.com:40599/ …`。

> **这条值得记住**：改完后端看不到效果时，先 `Get-NetTCPConnection -LocalPort 8789` 看进程的 `CreationDate`，不要相信启动脚本的"已停止"。

### 2.4 320px 顶栏溢出 19px

品牌 99 + gap 12 + 导航 214 + 两侧 padding 44 = 369 > 320，最右边的「说明」挂在屏幕外。
加 `@media (max-width: 380px)` 收窄 padding 到 10px、gap 到 8px、导航项 padding 到 5px。
修后实测 320/360/380 溢出为 0；381 以上走原规则，也仍是 0（导航右沿 339 / 311 两档）。

### 2.5 手机上手输的长 URL 被切掉

320px 下 `222px` 的文字塞进 `162px` 的盒子里（`scrollWidth > clientWidth`），URL 没有断行机会。
`.msg .body { overflow-wrap: anywhere }`，但 `pre` / `pre code` 保持 `normal`（代码块的行结构就是内容，它有自己的横向滚动）。
修后实测 320 / 390 / 1440 三档「被裁」计数均为 0。

### 2.6 窄屏把键帽藏了等于没说

原来 900px 以下 `.palette-foot kbd { display: none }`，页脚只剩「选择 / 执行 / 关闭」三个词——「选择」配不上任何信息，`↑↓` 才是那句话的内容。
改成 `flex-wrap: wrap`：390px 仍是一行（39px 高），320px 多占一行（59px 高，盒子有 74vh 可用）。

### 2.7 空结果的计数器是空白

搜不到时列表显示「没有匹配」，右下角却什么都不显示，读起来像还没加载完。改成 `0 项`。

## 3. 明确拒绝的做法（有理由，不是偷懒）

- **不要单字母快捷键 / `/` 聚焦**：输入框里打的是中文，输入法组字期间的单键会被吞或者误触。能用的只有 `Ctrl/⌘+K`、方向键、`Enter`、`Esc`——全部在文本框之外或面板之内。
- **不要霓虹黑底**：用户先要「整体白色打底」，且已捕获行的绿是全页唯一的满铺饱和色，是"结果"不是"装饰"。查过 ui-ux-pro-max 的样式库，`cyberpunk-ui` 要求深底荧光，与这个前提直接冲突。
- **没做方向键切任务轨**：`.rail-item` 本身不可聚焦，要做就得改标记结构，属于另一块工作，记在 §5。
