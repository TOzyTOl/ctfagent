# CTFAGENT 界面设计说明

## 设计命题

这个产品的用户是**比赛中的操作员**：同时盯多道题、多路 agent，时间有限，注意力是稀缺资源。所以界面不是"仪表盘"，而是一块**调度板（dispatch board）**——就像调度室墙上挂着的那块板：每道题一张工单（docket），工单上盖着状态章，旁边写着耗时和花费，完成时把结果"打印"出来。

这一版的视觉世界是**暗掉的调度台，上面有一张纸**：整块界面是一间熄了灯的调度室——近黑的地面，32px 一道工程网格，所有东西彼此只隔一条发丝线；**整个画面里只有一样东西是亮的，那就是纸**。纸不是一种颜色，而是一种材料，它只在**有东西被生产出来**的地方出现：已确认的 flag、已捕获的工单、写好的报告。它一出现，屏幕那一块就变成一张打印件。这一次反转是全页唯一的对比动作，也是其余一切必须保持暗、保持安静的理由。具体地：

- **地面**：`--board` → `--board-2` → `--board-3` 三档近黑，档与档之间只差一点点（1.08:1、1.13:1）——层次靠发丝线和那一枚内高光，不靠明度跳跃。页面背后叠一层 32px 的工程网格（`--grid`，`rgba(232,238,244,.028)`），顶上一团极弱的冷光（`--lamp-pool`），让"这是一块被照亮的操作面"成立而不给任何东西上色。
- **字**：Bahnschrift（工业 DIN 系，Windows 自带）承担界面与标题；Cascadia Mono 承担所有数据（编号、金额、耗时、命令、日志）；Sitka（衬线）只用于**报告正文**——那是另一种文档，不是界面。
- **章**：状态用"边框小章 + 字形 + 词"表达，颜色只是辅助（色盲可读）。

## 唯一的强动作

整块板保持安静、密集、低饱和，通篇是暗地与冷白的墨字。**唯一的高对比时刻是东西被生产出来**：任务轨里那个已捕获的行**整行变成一张纸**——浅纸底、墨字，页面上多出一块亮面；任务页上那张已确认的 flag 卡、以及 writer 写的报告，是同一张纸。这是产品的结果，所以它独占全部视觉重量——全界面只有这几处允许出现满铺的亮面。

纸之所以比"填一块绿"更强，是因为深色底上一块饱和色只是又一块色块，而一块纸是**另一种物质**：它把这一行从"数据"变成"成品"。同时它解决了白底时代的相反问题——报告正文在暗底上读不了长文，而在纸上它就是一份文档。

因此其他一切都**不填色**：主按钮用冷白实底（它是"现在就该点这里"，不是结果），其余按钮是描边的；空状态是空的暗面，不用灰块冒充内容。

**三级文字梯度在最亮的一层地面（`--board-3`）上测量**，因为深底下越往上的面，浅色字越弱：chalk 13.86:1、dim 7.84:1、faint 6.21:1（`--board` 上分别是 16.97 / 9.59 / 7.61）。强调色在 `--board-3` 上：ochre 7.17、blue 8.11、green 7.69、red 5.94。

**纸不是把暗色 token 反转过来就能用的**：暗色值在纸面上普遍只有 1.0–1.9:1。所以 `--paper-*` 是一套单独测量的阶梯——墨 `#0c110f` 在纸最亮处 17.20:1、最暗处仍有 14.65:1，次级墨 7.74:1（最暗处 7.10:1）；纸上的四个强调色（6.98 / 6.12 / 6.74 / 5.88）全部过 AA。两条主线之间的互反：纸底上的墨字是 15.98:1，冷白实底上的地色字是 16.97:1（按下 13.50:1），纸与地本身相距 16.64:1——这就是"唯一的对比动作"在数字上的样子。纸的分隔线 `--paper-rule` 是 1.56:1，只做结构、不承载信息。

换底色必须重新测量，不能沿用旧值。


## 光：唯一的渐变语言

渐变在这块板上只做一件事——**描述光落在一个实物表面上**，不做颜色效果，不做"AI 紫蓝渐变"。整套界面只有一盏灯，位置在页面上方偏后，所以凡是有厚度的东西都遵守同一条规则：**上缘受光、下缘背光**。

深底上这套规则的方向要跟着翻：浅底时代"最暗的一档"是次要文字最弱的地方，深底时代反过来——**最亮的那一档**（`--board-3`）才是，所以每一条对比都是先在 `--board-3` 上量的。

| 用在 | 渐变 | 范围 | 为什么 |
|---|---|---|---|
| 地面（`body`） | 顶部一团径向冷光（`--lamp-pool`）叠在 `--grid` 上 | 最亮处只比底色高一点点 | 眼睛先进页面顶部；`background-attachment: fixed`，内容从固定光晕上滑过，不会把渐变"拖着走" |
| 顶栏 | 与地面**完全相同**的光晕与网格，实底（`--lamp-pool-solid`） | 0 | 整页滚动的那几页（说明/比赛/凭据）正文会从顶栏底下穿过；顶栏填的是它盖住的那块地面本身，所以没有内容经过时它根本看不出来，有内容时文字不会糊在一起 |
| 板面（`.ws`、卡片） | `#141b24` → `#10151c` → `#0d1218` | 三档近黑，差值几个点 | 让"这是抬起的板、后面那是地面"成立，代价只有一条发丝线的明度；每块板另加一条 1px 内高光（`--lit-edge`）代替投影——深底上投影读不出来 |
| 任务轨 | `#0c1218` → `#0a0f16` → `#080d12` | 比板面再低一档 | 任务轨在层级里比对话板低半档，光弱一点 |
| 纸（已捕获行 / 已确认 flag / 报告） | `--paper-sheet`：`#f2f4ef` → `#e9ece7` → `#dfe3dc`，上受光下背光 | 三档浅纸 | 纸是唯一亮面，所以它必须是**受光材料**；同时这一档渐变让 15.98:1 的墨在任何一点上都够读（最暗处仍有 14.65:1）。纸带投影（`--paper-lift`），因为投影只有在浅色面上才有意义——那正是"它比地面高一层"的证据 |
| 控件（主按钮、气泡、跳过链接、回到底部、toast、键帽、输入井、侧栏、任务轨行） | 同一盏灯，**在物体尺度上**：按钮/气泡/选中行 `#202731` → `--board-3`；键帽 `--key` → `#1e2732`；输入井 `#0b1016` → `#131920`（井是**凹**的，所以顶缘暗、下部亮，方向与凸起物相反）；侧栏 `--board-3` → `#161c25`；说明页小节线 `--rule` → 透明，从左到右淡出 | 每处只差 6–10 个点 | 一个按钮和一张板用同一条光源位置，页面才像一张桌子上的东西。控件尺度上的渐变是**读得出来的体积**，不是色效：差值一小到看不出方向，它就只是"这块面有点脏" |

浅色填充本身也是表面，所以它们同样受光：主按钮/气泡/跳过链接/回到底部/toast 走 `--chalk-sheet`（`#f7fafd` → `#e8eef4` → `#dfe6ee`），按下态走 `--chalk-sheet-press`。它们的字是 `--board`，在三档上分别是 18.93 / 16.97 / 15.76，按下态 15.31 / 12.42。

**键帽的方向是反的，而且必须反**：键帽顶面抓光、往下落，所以它从 `--key` 往下走而不是往上提亮。提亮会把键帽上的 `--chalk-faint` 从实测底线 5.34 压到 4.76——虽然仍是 AA，但已经把余量用光了。

**每一条都在最弱的那一档上测对比度**：深底看 `--board-3`（chalk 13.86:1、dim 7.84:1、faint 6.21:1），浅纸看 `--paper-shade`（墨 14.65:1、次级墨 7.10:1）；控件尺度按各自最亮（或最暗，对"井"而言）的一档量。任何一档变暗或变亮，都必须重测这一列。


页面显式声明 `color-scheme: dark`（写在 `:root` 里，不是单独的规则）：否则浏览器会把 `select`、`checkbox`、滚动条这些原生控件按浅色平台主题画在一块近黑文档上，白得刺眼；同时它也告诉浏览器"网页自动深色"不必再反色一次。

另外几处"浏览器自己画的"也归调色板：选区用冷蓝薄层（`rgba(121,192,232,.26)`），焦点环用 `--chalk`，滚动条滑块用 `--rule`，插入光标用 `--ochre`——深底上系统蓝是唯一会自己出现的颜色。纸面上则全部由 `--paper-*` 接管，不能让任何暗色 token 漏进去（它们在这张纸上只有 1.0–1.9:1）。

## 排版

- 标题与界面：`Bahnschrift`（condensed 变体用于密集标签）
- 数据：`Cascadia Mono`，加 `font-variant-numeric: tabular-nums`
- 报告正文：`Sitka Text`（行宽 ≤ 72ch）
- 标签用句首大写 + 字距，不用全大写；但**分类表头**和数据编号保留等宽大写/字距，那是数据。

## 布局

界面以**对话**为第一入口：操作员的日常动作是"把题目和附件丢给大模型"，而不是先整理目录。调度板退到左侧，成为常驻的**多任务窗口**。

页面上每块板之间是 8px 的桌面空隙，四周同样留 8px：分栏靠空隙 + 一条发丝线读出来，不用成堆的圆角卡片。地面不是纯色，而是那层 32px 工程网格（`--grid`）——它给"这是操作面"提供密度，而且足够淡（灰度约 2.8%）到不与任何文字争。

```
 桌面（8px 边槽，近黑 + 32px 网格）
┌ 顶栏：品牌 · 沙箱/会话/端点 · 新任务/工作台/比赛/凭据/说明 ─────┐
├ 任务轨（252px）  ┬ 对话（主，宽）              ┬ 工作产物（372px）  │
│ ＋ 新任务         │ 题目名            ◐运行中   │ 工单 Flag 黑板 日志 │
│ ─────────────    │ ────────────────────────   │ ─────────────────  │
│ #6 silentrotor   │ 你：题目原文…（右侧气泡）    │ crypto  ▸ running  │
│   ◐运行中 1      │ 主 agent：收到，先拆三块…   │ Brute-force …      │
│ #5 n17           │                             │                    │
│   ⚑已捕获（纸面） │                             │                    │
│   flag{…}        │  ┌ 输入框 ───────────────┐  │                    │
│ ─────────────    │  │ ＋附件        发送     │  │                    │
│ 1 已捕获 3 进行中 │  └───────────────────────┘  │                    │
└──────────────────┴─────────────────────────────┴────────────────────┘
```

- **任务轨**：每个 run 一行，显示编号、名字、状态章、花费和最后一条动态；运行中的排前面，**已捕获的整行变成一张纸**（浅纸底、墨字、带一点纸面投影，像一张被判了"完成/归档"的单子）。点一下即切换，不需要回列表页。行之间用 `--rule-soft` 细线，选中行是高一档的暗底加左边一道冷白线——**选中行本身也是纸的时候，那道线要换成纸上的墨**（`--paper-ink`），否则它在纸上等于消失；窄屏把左边线换成下边线时同理，用 `--paper-ochre`。
- **对话**：与主 agent 的会话，支持中途补线索、再上传附件。操作员自己的话是**右侧气泡**，agent 的话是开放式正文（不加边框，因为它不是一条"消息"，而是一段工作记录）。旁边的「报告」页签放 writer 的 writeup——那是纸，用衬线。
- **工作产物**：工单、flag、黑板、实时日志四个页签。日志保留原来的实时事件流与"隐藏工具返回"开关；日志落在地面那一档（`--board`），因为它是原始输出，压在板下面而不是浮在板上。

窄屏（≤1080px）时工作产物移到对话下方；手机上（≤760px）任务轨变成顶部横向滚动的标签条。

新任务页复用同一条任务轨，右侧是一块**对话式首页**：一句标题（「今天解哪道题？」）、一行说明、三张示例（crypto / web / misc，点一下把示例填进输入框），然后就是唯一的输入框。示例排成一条共边框的行、内部用竖线分开，而不是三张浮起来的卡片。输入框是浮在板面上的一只圆角盒子（8px 圆角，比别处都圆，因为它是唯一一个"要你打字"的物件），聚焦时只把边框提亮到 `--chalk-faint`，不加发光。附件点「＋ 附件」选，也可以拖进页面任意位置——拖入时整页浮出一层薄纱，松手即附上；已选文件在输入框下方排成可删的小标签。Enter 发送，Shift+Enter 换行。目录登记、标题/分类/远程地址/flag 格式这些补充项折在输入框下方的 `补充字段（可选）` 里，不占首页的视觉重量。

第一条消息不走"表单提交后另起一轮"，而是**作为操作员的第一条对话**记录进会话：工作台打开时，最上面就是他自己写的那句话和附件卡片，主 agent 的回复接在后面。主 agent 的回复按 token 流式写入一个临时气泡（带闪烁光标），整段到齐时换成正式消息——临时气泡不落库，正式消息才是刷新后看到的那条，两者文本一致。

工作台的对话里，附件是**文件卡片**（名字 + 类型 + 点击下载），而不是一串文件名文本。

### 比赛页

比赛页是**赛前**用的，不是赛中用的，所以刻意比工作台安静：一条连接表单，然后每场比赛一张卡片——卡片头是这场比赛自己的计分（已解/总数、花费、耗时），下面是一张题目表。

```
┌ 比赛 ───────────────────────────────────────────────┐
│ 连接一个新比赛：[比赛名] [平台地址] [API Token] [连接并验证] │
├──────────────────────────────────────────────────────┤
│ DASCTF 十月赛   https://ctf.example.com · ctfd        │
│                          3/12 已解  $1.84 花费  47 分钟│
│ [同步题目与附件] [全部开跑]   上次同步 …                │
│ ┌ 题目 ─────┬ 方向 ──┬ 本地状态 ──┬ 附件 ┬ ────┐    │
│ │ Baby Web  │ web    │ 已捕获      │ 1    │ 打开 │    │
│ │ Old One   │ crypto │ 未开跑      │ 0    │ 开跑 │    │
│ └───────────┴────────┴─────────────┴──────┴──────┘    │
└──────────────────────────────────────────────────────┘
```

- **计分用本地数据算**，不用平台排行榜：花费和耗时是操作员真正关心的，平台的分数解释不了它们。
- **同步和开跑分开**：同步只是拉题，开跑才花钱。一次同步完可以先看题目表再决定先跑哪道。
- **提交是确认之后的第二个动作**。flag 卡片上，确认前只有「确认 / 驳回」，确认后才出现「提交到 <比赛名>」。这是全系统唯一会对外写数据的按钮，所以它必须是一个独立的、有名字的点击，而不是确认的副作用。

## 动效

一个曲线：`--ease: cubic-bezier(.22, 1, .36, 1)`。多数距离在前三分之一里走完，所以东西是**被放到位**的，不是滑过去的；尾巴长，所以它是停稳而不是刹住。不用弹簧、不用回弹——这块板是一张调度台，弹一下是它不会讲的笑话。

**只有一个被作者写下来的时刻：结果落纸。** 也就是一次 flag 刚被确认、任务轨上那一行刚变成纸的时候（`sheet-settle`，340ms）。它是服务端渲染的，所以这段动画不能挂在元素上——那样每次刷新都会把屏幕上所有已解出的行重播一遍。做法是：`reloadSoon` 触发刷新前，把刚确认的 run id 写进 `sessionStorage`；回到新页面后只给那一行加 `.just-captured`，加完就把它摘掉。

这里有一个必须写下来的坑：**任务轨每 5 秒自己 `fetch` 一次并把 `#rail-list` 整个换掉，而启动时那一次刷新甚至就落在动画播放途中**。标记加在旧节点上，新旧一换就没了。所以 id 还要在这个模块里多留 1.5 秒，每次换新列表都补一次；时间一到就清掉标记并停止补——否则一个五分钟前的结果会在每次轮询时重新跳一下。

其余三处都只是**状态变化**，快到眼睛读作"状态"而不是"入场"：

| 动效 | 时长 | 为什么值得 |
|---|---|---|
| 命令面板出现（`palette-in`） | 160ms | 面板是盖在页面上的一层，2% 的抬升读作"从前面来"；再长一点，那个全部职责是"立刻"的控件就要让人等了 |
| 新消息、新日志行、新 worker（`ink-in`） | 200ms | 位移 2px：够看出"这行是新的"，小到一屏繁忙日志不会跟着起伏。**只给这条流新来的行加**，服务端回放的历史和重连补发的积压不加，否则每次进页面日志都会闪一遍 |
| 任务轨、tabs、按钮的 hover/focus | 120ms 内 | 只过渡颜色；任何带渐变的 `background` 都拆成 `background-color`（过渡）与 `background-image`（瞬时）——渐变没有中间值，用 `background` 一起过渡会在图像底下把颜色淡成透明 |

流式回复末尾的方块光标、状态章上的运行中闪烁照旧。**`prefers-reduced-motion` 一条开关关掉全部动画和过渡**；`.just-captured` 这个类仍然会加上，只是不再动——操作员要求不动，结果还是结果。

## 极客层：语法与键盘

"极客感"不用霓虹和荧光来表达——那是另一套人设，而且会和"唯一的亮面是纸"这条规矩直接打架。这块黑底板的做法是**把页面的语法写成命令行的语法，再把键盘当真**：颜色已经够"机器"了，所以极客感走语法，不再往上加光。

- **一个记号，一种意思。** 画的直角小箭头（`border-right` + `border-bottom` 旋转 45°）代表"机器在这里开始说话"：运行身份行、主 agent 的每一轮发言、命令面板的输入头都是它。日志里每条事件前面是 `›`。记号是画的不是打字的——`❯` 这一类字形在几种等宽字体里没有，会静默变成豆腐块，而这恰好是整页最需要显得精确的一行。
- **命令面板（Ctrl/⌘ + K）。** 顶栏右边的「跳转 Ctrl K」既是入口也说明键在哪——快捷键没人看过就等于没有。面板只有一个输入框、一份排名好的清单和一条键盘说明：页面 → 动作 → 任务，任务行同时用编号和题目名检索（`#121` 能搜，题目名也能搜）。方向键游走全部匹配项，渲染出的 40 行只是窗口，走到边界会往下延；列表面板负责焦点，Tab 不会把焦点漏到背后的页面上。
- **键帽是真键帽。** `kbd` 有发丝边、底边加粗一档，像桌上印好的东西：顶面受光、往下落（`--key-ramp`，`--key` → `#1e2732`），所以有厚度而没有内阴影。方向必须是往下——往上提亮会把键帽上的 `--chalk-faint` 从 5.34 压到 4.76。键帽在窄屏也不藏——只有「选择」两个字的提示什么也没说，`↑↓` 才是那句话的内容，所以这一行在 320px 上允许换行而不是删掉键帽。
- **只绑不抢字的键。** 没有单字母快捷键，也没有 `/` 聚焦：输入框里打的是中文，输入法组字期间的单键会被吞掉或者误触。能用的是 Ctrl/⌘+K、方向键、Enter、Esc，全部在文本框之外或面板之内。
- **跳转链接。** 任务轨一天能堆九十来个链接，键盘用户不该先走过它们。第一个 Tab 停靠的是「跳到正文」，它平时在视口上方，聚焦时落到顶栏下面——header 是 sticky，所以 `html` 上有 `scroll-padding-top`，任何被滚到的目标都不会藏到栏底。

## 代码块与复制

代码在这块板上出现得比正文还多：命令、脚本、返回值、flag。所以围栏代码块有自己的一小块界面——**一条细栏 + 一块凹进去的板**，而不是排在正文里的一块灰底。

- **栏上只有两样东西：语言、复制。** 语言是围栏信息串（```` ```python ````），它是**数据**，所以走等宽字体、`--chalk-faint`、字距；右边一个描边按钮「复制」。栏底比代码板亮半档（`--board-2`），因为它是一条**控制条**，不是代码本身。栏的圆角只有上面两角，下面与 `pre` 的直角对齐——`pre` 自己要横向滚动，所以外面那层壳**不能** `overflow: hidden`，否则长行的滚动条和超出的字会一起被裁掉。
- **语言标签是唯一的"我在读什么"提示**，所以没有语言时它显示 `code`，而不是留空。没有语言的围栏是**粘贴的结果**（接口返回、报错输出），不是源码，所以**不做高亮**——给一段 `{"ok":true}` 上色只会骗人。
- **高亮的七个色位是一套，不是一个。** 关键字、字符串、数字、注释、类型、调用、装饰器各一个 token，全部在**最坏的那块板上**量过：暗地的代码块是纯 `--board`（`#070a0e`，比板面还低一档，因为它是"凹进去"的），七个值分别是 9.10 / 11.08 / 9.32 / 6.37 / 10.20 / 10.56 / 9.03；纸上的代码板是 5.5% 墨压在纸最暗那一档上（`#d3d7d1`），七个值 6.74 / 5.02 / 5.61 / 6.33 / 5.51 / 6.06 / 5.94。**最低的一格是纸上的字符串 5.02，所以纸面那一套必须单独取色，不能拿暗色值直接翻转**——暗色值到了纸上只有 1.0–2.0:1。
- **两个渲染器必须吐出同一份标记。** 服务端 `ctfagent/mdrender.py`（Jinja 的 `markdown` 过滤器，刷新时走）和 `app.js` 的 `renderMarkdown()`（流式时走）各写了一遍围栏处理，语言串都要过同一条白名单 `[A-Za-z][A-Za-z0-9+#._-]*`：它最后要落进 `class="lang-x"`，围栏里写什么都不能写进属性。不过白名单的围栏**不报错、也不上色**，只是没有那个 class。**没写语言的围栏必须逐字节等同于旧输出**（`<pre><code>`），否则一次刷新就把同一条消息的形状改了，`tests/test_chat_markdown.py` 里对精确字符串的断言也是这么钉住的。
- **复制按钮有两种，位置不同。** flag 卡上是值旁边一个显式按钮（值是 30 来个字符、要粘到别处去的记号，藏在整行文字上等于没人找得到）；代码块上是栏里那一个。两者都读**纯文本**，不是 `innerHTML`——高亮之后的 `<code>` 里全是 `<span>`，`textContent` 才是原样。
- **剪贴板要有退路。** `navigator.clipboard` 只在安全上下文里有；本机 `127.0.0.1` 算，但同一台机器上的手机用局域网 http 打开时没有这个 API。所以失败时走 `execCommand("copy")` 选中一个屏外 `textarea`；再失败就提示"请手动选中"。**一个静默失效的复制按钮比没有按钮更糟**，这条退路就是为此存在的（浏览器实测：正常路径写入的文本与源码逐字节相同；`execCommand` 退路在真实点击下 `ok: true`，并且写入的正是同一个字符串）。
- **只装饰"写下来的那条"消息，不装饰流式气泡。** 流式气泡每来一个 token 就整个重建 `innerHTML`，在那里挂栏会被一秒拆装几十次。所以 `decorateCode` 只在消息落定（追加进对话）和报告加载完成时跑一次。
- **日志不是代码。** `pre.console` 被显式跳过：它是事件流，已经用自己的颜色分类型；再套一层代码高亮会把两套语法叠在同一个位置。
- **纸上要换一条焦点环。** 全站焦点环是 `--chalk`，在深色地面上是 15.68:1，但**到了纸上是 1.02–1.11:1，等于没有**。所以纸面的可聚焦控件——这张新加的 flag 复制按钮、代码块里的复制按钮、报告里的链接、已捕获行的链接和删除按钮——焦点环换成 `--paper-ink`（纸最暗那档 `#dfe3dc` 上 14.65:1）。这是**旧版就有的缺口**：已捕获行的链接和删除按钮一直是这样，只是这一轮把两个新按钮也放了进去，才顺手一次补齐。

> 报告页的宽度有一次真实的翻车：`.writeup` 靠 `margin: 20px auto` 居中，而 pane 是列向 flex——**横向的 auto margin 会关掉 stretch**，盒子于是按 max-content 取宽。一段很长的代码虽然自己 `overflow-x: auto`，但它的固有宽度照样算进 max-content，于是 320/390px 视口里整份报告撑到 684px，只剩一条横向拖动才能读。修法是给 `.writeup` 加 `width: 100%`（`max-width: 820px` 仍然在宽屏上让它居中）。这跟 `.doc-wrap` / `.page` 是同一条坑，说明页那节早就记过一次。

## 说明页（Read 模式）

说明页是长文阅读，与工作台同一块暗地面，不另立一套视觉：靠三件事立结构——860px 的行宽上限、每个小节一条横线的标题节奏、正文 14.5px / 行高 1.8 的阅读字号。列表序号用等宽字体、降一档灰，把"编号是数据"这件事延续到文字页里。绿色在这里同样只表示"解出"，不用作装饰。

> 行宽上限必须配 `width: 100%`。`.doc-wrap` 是 `.frame` 这个列向 flex 的子元素，横向的 `margin: auto` 会取消 stretch，盒子于是按 fit-content 取宽——页里一段 `pre` 有多宽，整页就有多宽（实测 320px 视口里撑到 456px，`pre { overflow-x: auto }` 永远轮不到出手）。`.page` 是同一个形状，一起加了。

## 明确避免

- 近黑 + 荧光绿/朱红的"黑客配色"：**底色可以黑，"荧光"不可以**。这一版的深色地面靠发丝线、网格和一团极弱的环境光立结构，不靠发光——任何 `text-shadow` 光晕、霓虹描边、带色投影都不出现
- 反过来"白底 + 荧光绿"的终端配色
- 奶油底 + 高对比衬线 + 陶土色的通用 AI 版式
- 等距圆角卡片堆叠、统一柔和阴影
- 每个标题上方的全大写字距标签
- 用 `·` 拼接的元信息串、链接尾部加 `→`
- 把颜色当"强调背景"使用——绿色是结果，不是装饰；暗底上的**满铺亮面只有纸**（已捕获行、已确认 flag 卡、报告），且必须走 `--paper-sheet` 那张纸的渐变，不能填一块纯色
- **把纸当装饰用**：纸是"这里生产出了东西"的物理证据。没有结果的地方放一块浅色，整套语法就废了
- **渐变当颜色效果**：紫蓝"AI 渐变"、彩条 hero、文字渐变、装饰性光晕一律不用；渐变只允许出现在上一节那张表里，作为光的描述
- 带色光的投影（绿色发光的卡片）：深底上投影本来就读不出来，抬升一律用 1px 内高光（`--lit-edge`）或纸自己的 `--paper-lift`
